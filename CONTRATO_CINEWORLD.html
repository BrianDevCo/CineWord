Cláusula Primera — Objeto del Contrato

EL DESARROLLADOR se obliga a diseñar, desarrollar y entregar un sitio web de venta de boletos en línea para el establecimiento comercial CINEWORLD, ubicado en el Centro Comercial MR Outlet, conforme a las especificaciones técnicas detalladas en la Cláusula Segunda del presente contrato.

El producto entregado es un sistema web completo que incluye: página de presentación institucional, cartelera dinámica de películas, sistema de compra de boletos con selección de asientos, pasarela de pago integrada con MercadoPago, sistema de autenticación de usuarios, y módulo de notificaciones por correo electrónico.

Cláusula Segunda — Especificaciones Técnicas del Proyecto

El sitio web desarrollado comprende única y exclusivamente los siguientes módulos, funcionalidades y componentes, los cuales constituyen el alcance total del presente contrato:

2.1 Tecnologías Utilizadas

ComponenteTecnología
Framework FrontendNext.js 16 (App Router) con React 19
Estilos y DiseñoTailwind CSS v4 — diseño responsivo mobile-first
Base de Datos y AuthSupabase (PostgreSQL + autenticación JWT)
Pasarela de PagosMercadoPago Checkout Bricks (pago embebido)
Correo ElectrónicoResend — emails transaccionales automáticos
Hosting RecomendadoVercel (deploy automático desde repositorio)
LenguajeTypeScript (tipado estricto)

2.2 Módulo Institucional — Página Principal

SecciónDescripción
NavbarBarra de navegación fija con logo, links a secciones, botón de acceso a cuenta e ícono de modo claro/oscuro
HeroBanner principal con imagen de fondo, eslogan, llamada a la acción y video de fondo opcional
CarteleraGrilla de películas activas con filtros por género y formato, cargadas dinámicamente desde la base de datos
PromocionesSección de combos y descuentos vigentes con diseño visual destacado
Próximos EstrenosPelículas próximas con opción de registro de correo para recibir notificación de estreno
SalasPresentación de las salas disponibles del complejo (capacidad, tecnología)
SnacksMenú visual de confitería con precios
ContactoInformación de ubicación, horarios de atención y formulario de contacto
FooterPie de página con links, redes sociales y datos legales del negocio

2.3 Módulo de Detalle de Película

  • Página individual por película con URL propia (/pelicula/[id])
  • Hero cinematográfico con imagen de fondo, póster, badge de clasificación, género, duración
  • Sinopsis, ficha técnica (director, reparto), enlace al tráiler oficial en YouTube
  • Sección de compra de boletos integrada en la misma página
  • Carrusel de otras películas en cartelera al pie

2.4 Módulo de Compra de Boletos (Flujo de 5 Pasos)

  1. Selección de fecha — Próximos 7 días con funciones disponibles
  2. Selección de formato — 2D, 3D, IMAX, según disponibilidad por función
  3. Selección de horario — Funciones filtradas por fecha y formato
  4. Selección de asientos — Mapa visual de la sala; asientos disponibles, ocupados y seleccionados diferenciados por color; temporizador de reserva de 5 minutos
  5. Pago — Resumen de compra y brick de pago embebido de MercadoPago

2.5 Pasarela de Pagos — MercadoPago

  • Integración con MercadoPago Checkout Bricks (pago embebido, el usuario no abandona el sitio)
  • Soporte para tarjetas crédito, débito y PSE
  • Manejo de estados: pago aprobado, rechazado y pendiente
  • Webhooks para notificaciones automáticas de MercadoPago
  • Páginas de resultado personalizadas para cada estado (éxito, fallo, pendiente)

2.6 Módulo de Autenticación de Usuarios

  • Registro con correo electrónico y contraseña (con confirmación por email)
  • Inicio de sesión con correo y contraseña
  • Inicio de sesión con Google (OAuth 2.0)
  • Recuperación de contraseña por correo electrónico
  • Establecimiento de nueva contraseña
  • Cierre de sesión
  • Flujo de invitado: navegación libre sin login; login requerido únicamente al momento de pagar

2.7 Módulo de Cuenta de Usuario

  • Página /cuenta protegida por autenticación
  • Historial de reservas con detalle: película, fecha, horario, sala, asientos, valor y estado del pago

2.8 Notificación por Correo Electrónico

  • Email automático al comprador tras pago aprobado
  • Contenido: nombre del comprador, película, fecha, horario, sala, asientos asignados
  • Código QR único del boleto generado y embebido en el correo
  • Diseño del email con identidad visual de CINEWORLD

2.9 Base de Datos — Esquema Supabase

TablaDescripción
peliculasCatálogo de películas en cartelera y próximas
salasSalas del cine con capacidad y configuración de filas/columnas
funcionesProgramación de funciones por película, sala, fecha y formato
reservasRegistro de compras realizadas por usuarios
asientos_ocupadosControl en tiempo real de disponibilidad de asientos por función
notificaciones_estrenoCorreos registrados para notificación de estrenos

El esquema incluye políticas de seguridad a nivel de fila (Row Level Security — RLS) para proteger los datos de cada usuario.

2.10 SEO y Aspectos Técnicos

  • Metadatos optimizados por página: título, descripción, Open Graph (WhatsApp, Facebook), Twitter Card
  • Imagen de previsualización para redes sociales (1200×630 px) generada automáticamente
  • Mapa del sitio dinámico (sitemap.xml) con todas las películas activas
  • Archivo robots.txt configurado para indexación correcta
  • Favicon e ícono personalizado con identidad CINEWORLD
  • Página de error 404 personalizada
  • Datos de respaldo estáticos: el sitio funciona visualmente aunque Supabase no esté configurado
  • Revalidación de caché cada 5 minutos en páginas de cartelera y detalle

2.11 Panel de Administración Web

  • Acceso privado para el administrador del cine (usuario y contraseña propios)
  • Gestión de películas: crear, editar y desactivar películas en cartelera y próximos estrenos
  • Gestión de funciones: programar horarios por película, sala y formato
  • Gestión de precios por sala y formato
  • Visualización de reservas realizadas: listado con filtros por fecha, película y estado de pago
  • Gestión de salas: capacidad, configuración de filas y columnas

2.12 Integración con Sistema POS Score

  • Conexión entre el sitio web y el sistema Score utilizado por CINEWORLD para la venta presencial
  • Sincronización de disponibilidad de asientos en tiempo real entre ambas plataformas
  • Sincronización de reservas: las compras realizadas en el sitio web se reflejan en Score y viceversa
  • Nota: Esta integración está condicionada a que el proveedor de Score facilite acceso a su API o mecanismo de integración. EL DESARROLLADOR realizará la integración técnica una vez EL CLIENTE gestione y obtenga dicho acceso con el proveedor Score.

2.13 Gestión y Actualización de Contenido

  • Carga inicial de películas, funciones, salas y precios en la base de datos para el lanzamiento del sitio
  • Capacitación al administrador del cine para el uso del panel de administración
  • Documentación básica de uso del panel administrativo

2.14 Lo que NO incluye este contrato

Las siguientes funcionalidades no hacen parte del alcance del presente contrato y deberán ser objeto de un acuerdo independiente si el cliente las requiere:
