1. Antecedentes del Proyecto

En el marco del contrato suscrito entre las partes para el desarrollo del sitio web oficial de CINEWORLD, se acordó inicialmente un tiempo de ejecución de una (1) semana para la entrega del producto funcional. Dicho plazo contemplaba el desarrollo de la plataforma web, la integración con el sistema de pagos y la conexión con el sistema de gestión del cine (Score Projects S.A.S.).

2. Situación Actual — Extensión del Plazo

A la fecha, el proyecto acumula más de un mes de trabajo, superando ampliamente el tiempo pactado originalmente. Esta extensión no obedece a factores atribuibles al desarrollador, sino a una serie de inconvenientes técnicos externos originados en la relación entre el cine y su proveedor de software Score, tal como se detalla a continuación.

3. Causas Externas que Generaron el Retraso

Causa Descripción
Servicios de Score no habilitados De 8 servicios de la API de Score requeridos para la venta en línea, solo 3 están activos para el tercero asignado al cine. Los 5 restantes (SCOGRU, SCOLIR, SCOINT, SCOPLA, SCOCAR) devuelven error y deben ser habilitados por Score.
Problemas de conectividad con Score El servidor de Score opera en la red local del cine sin exposición pública a internet, lo que impidió la integración directa y obligó al uso de soluciones alternativas (túnel ngrok) mientras se gestiona el port forwarding con el proveedor de internet.
Reinicio del servidor del cine El PC que aloja el sistema Score se reinició sin previo aviso, interrumpiendo el túnel de conexión y generando horas adicionales de diagnóstico y reconfiguración.
Reuniones sin resolución Se participó en reuniones con el equipo de CINEWORLD pactadas como reuniones de "cierre", en las cuales no se resolvieron los bloqueos identificados, extendiendo el tiempo de gestión.
Tareas fuera del alcance del desarrollador web Se realizaron labores de diagnóstico de red, configuración de túneles, pruebas de conectividad, identificación de endpoints incorrectos y documentación técnica para Score — tareas que corresponden a infraestructura y no al desarrollo web contratado.

4. Trabajo Adicional Realizado

Más allá del alcance original, se desarrollaron e implementaron funcionalidades adicionales no contempladas en el acuerdo inicial, entre las que se destacan:

Funcionalidad adicional
Integración completa con Score API (encriptación AES-128-CBC, 8 servicios)
Sistema de hold de sillas en tiempo real con temporizador de 5 minutos
Mapa de sillas interactivo con ocupación en tiempo real desde Score (SCOESG)
Diagnóstico y configuración de túnel ngrok para acceso externo al servidor Score
Investigación y documentación de arquitectura de red del cine
Reuniones técnicas con proveedor Score para gestión de habilitación de servicios
Panel administrativo completo con gestión de películas, funciones y reservas
Sistema de emails automáticos con código QR del boleto

5. Ajuste de Honorarios

Dadas las circunstancias descritas — extensión del plazo por causas externas, trabajo fuera del alcance contratado, reuniones adicionales y gestión técnica no prevista — se hace necesario realizar un ajuste sobre el valor acordado inicialmente:

Concepto Valor
Valor pactado originalmente Según contrato
Incremento por extensión del plazo (causas externas al desarrollador) $200.000 COP
Incremento por trabajo adicional fuera del alcance contratado $100.000 COP
Incremento por reuniones adicionales sin resolución de bloqueos $100.000 COP
Total incremento $400.000 COP

Este ajuste se origina exclusivamente en factores externos al desarrollador. El sitio web fue entregado funcional en su totalidad. A la fecha, Score ha habilitado la totalidad de los servicios requeridos para la venta en línea, por lo que la plataforma se encuentra completamente operativa técnicamente. El presente comunicado constituye el cobro formal del valor adicional generado durante el proceso.

6. Estado Actual y Cierre

A la fecha de emisión de este documento, Score Projects S.A.S. ha habilitado la totalidad de los servicios de API requeridos (SCOGRU, SCOLIR, SCOINT, SCOPLA, SCOCAR, SCOCYA), lo que permitió completar la integración técnica de la plataforma. El sitio web se encuentra funcional y listo para operar con venta en línea.

Las reuniones de cierre están programadas con el equipo de CINEWORLD, y en ellas se formalizará la entrega definitiva del proyecto junto con el pago del ajuste de honorarios aquí descrito. Quedo disponible para cualquier aclaración sobre el presente comunicado.
